# KnowDB frontend

Next.js app for exploring infrastructure data in a Wikipedia-like manner.
The front page shows 10 random entries; every entry page links to
everything it is connected to, so you can navigate from a host to a port
to another host, and so on.

Host data is read from `data/hosts.json` (generated by
`../scripts/generate_hosts.py`).

## Run with the npm dev server

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Run in Docker

```bash
docker build -t knowdb-frontend .
docker run --rm -p 3000:3000 knowdb-frontend
```

Then open http://localhost:3000.

## Tests

Playwright tests live in `tests/`. The test runner starts the dev server
automatically:

```bash
npm install
npx playwright install chromium
npm test
```
